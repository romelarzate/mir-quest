Crear una PWA para estudiar el MIR de España con dashboard, asignaturas, biblioteca, preguntas, flashcards, simulacros, tutor ATLAS y arquitectura preparada para Gemini, Firebase, File Search y Predict 2027.

Reglas:
1. Trabajar únicamente dentro de este workspace.
2. No publicar en producción.
3. No gastar dinero.
4. No usar claves reales sin autorización explícita.
5. No borrar datos reales.
6. No tocar archivos fuera de esta carpeta.
7. No subir manuales protegidos a servicios externos.
8. Usar datos mock solo si están claramente marcados.
9. Mantener la app compilable.
10. Documentar cada fase.
11. Pedir aprobación solo para acciones sensibles.

Construir MIR Quest v0.1 como prototipo PWA navegable, premium, mobile-first y modular.
